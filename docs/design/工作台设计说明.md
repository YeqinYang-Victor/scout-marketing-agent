# 工作台设计说明（v2）

**中文** ｜ [English](workbench-design-notes.en.md)

> 面向**券商客户经理**的「今日日报」工作台改版设计。
> 交互原型：[`工作台设计稿.html`](./工作台设计稿.html) —— 浏览器直接打开，左上角可切换「空态 / 生成中 / 结果态」与「桌面 / 手机」。

---

## 一、用户与场景

**用户**：券商零售条线的客户经理（RM）。典型画像：

- 早上 7:30–9:00 通勤或刚到公司，需要快速找到「今天能发给客户的内容」；
- 主要触达渠道是**企业微信**，发的是文字 + 偶尔配图；
- **时间极度碎片化**，不会花 10 分钟研究一个系统；
- 手机使用频率高于电脑；
- 有明确的**合规红线**：不能给出买卖建议。

**核心任务（JTBD）**：
> 「给我一条今天能直接发给客户的内容，越快越好，而且别让我踩合规的坑。」

## 二、六条核心设计判断

### 1. 从「系统控制台」改成「工作台」

旧版把**流水线内部机制**当作主内容：9 步执行流程、五维打分明细、候选排行占据首屏。
这些是**研发关心的信息**，客户经理不关心「标准化与去重」「权重 0.38」。

**改法**：结果优先，机制后置。
- 9 步流程 → 折叠到「生成过程明细」，默认收起；
- 五维打分 → 折叠到「为什么选它？」，默认收起；
- 生成中只展示 **4 个用户能理解**的阶段（抓取资讯 / 筛选热点 / 撰写文案 / 生成配图）。

### 2. 唯一主操作

旧版右上角挤着「数据源 + 模板 + 大模型润色 + 一键生成」四组控件，主操作不突出。

**改法**：
- 全页只有一个**红色实心主按钮**，空态时居中放大、结果态时是「复制文案，发给客户」；
- 数据源 / 模板 / AI 润色降级为**胶囊状的「生成设置」**，放在主按钮下方，视觉上安静；
- 顶栏的「生成设置」也做成描边幽灵按钮，不与主操作抢注意力。

### 3. 文案是产品，所以要「所见即所得」

客户经理真正交付的是**那段文字**。旧版把文案放在一个 `<pre>` 里，复制按钮很小。

**改法**：
- 文案区做成**聊天气泡样式**，标注「以下为客户收到的完整内容」——让 RM 一眼知道客户看到的就是这个；
- 主操作直接是「复制文案，发给客户」，并补一句「复制后可直接粘贴到客户群」；
- 展示**字数 / 投放渠道 / 模板**等交付相关信息。

### 4. 把「事件」和「文案」合成一张卡

RM 的心智模型是「今天的日报 = 一个热点 + 一段话」，而不是两个独立模块。

**改法**：一张卡内自上而下是
`今日头号事件（标题/板块/关键指标）→ 客户文案（气泡 + 复制）`，
阅读路径自然：**为什么发这条 → 发什么**。

### 5. 合规状态要「看得见」

券商场景下，RM 最大的隐性焦虑是「这段话会不会违规」。

**改法**：
- 结果态顶部一条状态栏，第一个元素就是绿色「✓ 合规自检通过」；
- 侧栏底部固定一条绿色说明：「本文案不含买卖时机、仓位比例等投资建议，已自动附带风险提示与免责声明」。
- 这让合规从「隐性风险」变成「可见保障」。

### 6. 手机优先

RM 大量场景在手机上。原型内置了移动端形态：

- 左侧导航 → **底部标签栏**；
- 主操作 → **吸底大按钮**（拇指可达区）；
- 顶栏标题独占一行，操作按钮收成**纯图标**，避免挤压换行；
- 多列布局 → 单列堆叠。

## 三、信息架构

```
今日工作台
├── 顶栏        今日工作台 · 日期 ｜ 历史记录 · 生成设置 · 头像
├── 空态
│   ├── 欢迎卡    问候 + 唯一主按钮「生成今日日报」
│   ├── 生成设置  数据源 / 模板 / AI 润色（安静的胶囊）
│   └── 最近生成  近 3 次记录，可点击复用
├── 生成中
│   ├── 进度条 + 已用时
│   ├── 4 个阶段卡片（已完成 / 进行中 / 等待）
│   └── 骨架屏（预告结果形态，减少等待焦虑）
└── 结果态
    ├── 状态栏      合规自检 ✓ · 生成时间 · 模板 · 字数 · 重新生成
    ├── 主列
    │   ├── 今日日报卡
    │   │   ├── 今日头号事件（标题 / 板块 / 最强板块 / 得分 / 个股数）
    │   │   ├── 客户文案（企微气泡 + 复制主按钮）
    │   │   └── 操作条（复制文案 · 下载 Banner）
    │   ├── ▸ 产业链传导与受益方向      （折叠，默认展开）
    │   ├── ▸ 为什么选它？五维打分依据  （折叠，默认收起）
    │   └── ▸ 生成过程明细              （折叠，默认收起）
    └── 侧列
        ├── 配套 App 首页图（缩略预览 + 下载 PNG）
        ├── 接下来（导出 HTML / 换快讯版 / 查看历史）
        └── 合规说明
```

**折叠策略**：与「发出去的内容」直接相关的（产业链、受益方向）默认展开；
纯机制性的（打分依据、9 步流程）默认收起——需要时可查，不占首屏。

## 四、视觉规范

### 色板

| 用途 | 值 | 说明 |
|------|-----|------|
| 品牌主色 | `#C7000B` | 品牌红。**仅用于**：品牌标识、主按钮、关键数字、涨 |
| 品牌深色 | `#8E0007` / `#A20009` | 按钮渐变、banner 底 |
| 主文字 | `#14224A` | 深蓝，替代纯黑，更符合金融调性 |
| 次级文字 | `#4A5578` | |
| 辅助文字 | `#8A93AD` / `#B4BBCB` | 说明、占位 |
| 页面底 | `#F4F6FA` | |
| 卡片 | `#FFFFFF` | 边框 `#E9ECF3` |
| 涨 | `#C7000B` | **中国市场惯例：涨红跌绿** |
| 跌 | `#0F9D58` | |
| 强调 | `#E8A33D` | 进度条、上游环节标签 |

**红色的克制使用**是本次改版的关键：旧版把红色用在了所有进度条、图标、边框上，
导致页面发噪、重点不明。新版红色只留给「品牌 + 主操作 + 关键数字 + 涨」。

### 字号与行高

| 层级 | 字号 / 行高 | 用途 |
|------|------|------|
| 页面标题 | 17 / 1.3 | 顶栏 |
| 事件标题 | 19.5 / 1.5 · 700 | 头号事件 |
| 卡片标题 | 13.5 / 1.4 · 700 | 各卡片 |
| **正文（文案）** | **13.5 / 1.95** | 气泡内文案，行高给足便于长文阅读 |
| 辅助说明 | 11–12 / 1.6 | 指标名、描述 |

中文字体栈：`PingFang SC, Hiragino Sans GB, Microsoft YaHei, system-ui`

### 圆角 / 阴影 / 间距

- 圆角：卡片 16px、控件 9–11px、胶囊 999px
- 阴影：`0 1px 2px rgba(20,34,74,.05)`（静态卡）；
  `0 2px 6px -2px …, 0 12px 28px -14px …`（浮起卡）
- 主按钮阴影：`0 6px 18px -8px rgba(199,0,11,.55)`，hover 时上移 1px
- 间距节奏：8 / 12 / 15 / 18 / 24 / 40

## 六、与旧版对照

| 维度 | 旧版 | 新版 |
|------|------|------|
| 首屏主内容 | 9 步执行流程 + 五维打分 | 今日头号事件 + 可转发的客户文案 |
| 主操作 | 右上角，与 3 组控件并列 | 全页唯一红色主按钮，空态居中 / 结果态为「复制文案」 |
| 配置项 | 顶栏 Select + Switch，长期占位 | 降级为「生成设置」胶囊，或收进抽屉 |
| 文案呈现 | `<pre>` 纯文本块 | 企微气泡预览 + 交付信息（字数/渠道/模板） |
| 复制操作 | 卡片头部的小按钮 | 主按钮级，并提示「复制后可直接粘贴到客户群」 |
| 合规 | 只在文案末尾出现免责声明 | 顶部「✓ 合规自检通过」+ 侧栏合规说明 |
| 历史 | 无 | 空态「最近生成」+ 顶栏「历史记录」 |
| 移动端 | 未适配 | 底部标签栏 + 吸底主按钮 + 图标化顶栏 |

## 七、落地到现有代码的建议

现有技术栈为 React 18 + TDesign + Tailwind，改造可保持栈不变：

| 设计模块 | 落地方式 |
|----------|----------|
| 设计令牌 | 在 `tailwind.config.js` 的 `theme.extend.colors` 增加品牌色板（`brand` / `ink` / `line` / `up` / `down`），替换散落的 `#C7000B` 硬编码 |
| 状态栏 / 徽标 / 胶囊 | 抽成 `Badge`、`Chip`、`StatBar` 三个原子组件 |
| 三态切换 | `ScoutDashboard` 内部以 `view: 'idle' \| 'running' \| 'done'` 驱动，替换现有「左流程 + 右结果」的两栏常驻结构 |
| 折叠区 | 用原生 `<details>` 或 TDesign `Collapse`，默认值按上文「折叠策略」设置 |
| 气泡预览 | 独立组件 `CopyBubble`，内部仍渲染 `report.text`（`white-space: pre-wrap`） |
| 历史记录 | 复用已有接口 `GET /api/scout/runs`（列表）与 `GET /api/scout/runs/:id`（详情），无需后端改动 |
| 阶段进度 | 把现有 9 个 SSE `step.key` 映射到 4 个展示阶段，UI 层做一次归并即可 |

> **后端无需改动**。本次改版只涉及信息层级、视觉与交互，数据接口保持原样。

### 实现时新增的一处设计

**合规自检改为真实检查，而不是写死「通过」。**
`ScoutDashboard.tsx` 里的 `complianceCheck()` 会扫描文案中是否出现
「波段机会 / 逢低布局 / 仓位 / 止盈 / 止损 / 建议买入 / 必涨 / 稳赚 / 保本 / 目标价」等词。
命中则顶部状态栏与侧栏同时转为**红色告警**并列出命中的词。
这样当有人往模板里加了投资建议类表述时，界面会立刻暴露问题，而不是继续显示绿色的「通过」。

### 第二轮：全站风格统一 + Banner 断词修复（已完成）

**① 风格统一** —— 其余四个页面已套用同一套设计令牌与原子组件：

| 页面 | 改动 |
|------|------|
| `src/pages/SourcesPage.tsx` | 重写：`PageHeader` + `SectionCard` 骨架，卡片列表 + 右侧表单两栏 |
| `src/pages/RulesPage.tsx` | 重写：五维权重滑块、硬性过滤、关键词、行业黑白名单全部统一为同一卡片语言 |
| `src/pages/TemplatesPage.tsx` | 重写：模板列表 + 正文/字段编辑器统一卡片语言 |
| `src/components/Header.tsx` / `Sidebar.tsx` | 会话区顶栏与侧栏改为同款配色与圆角 |
| `src/index.css` | **把 TDesign 主题色从默认蓝改为品牌红**（`--td-brand-color` 等一整套变量），这是统一观感的最大杠杆；同时对齐中性色板与圆角 |
| `src/hooks/useAgents.ts` | 默认 Agent 头像色由脚手架蓝 `#0052d9` 改为品牌红 |
| `src/components/scout/atoms.tsx` | 新增 `PageHeader` / `SectionCard` / `Field` 页面级骨架组件；所有按钮补 `border-0`（Tailwind preflight 关闭时浏览器默认边框会外露） |

**② Banner 断词修复** —— `server/pipeline/banner.ts`：

- 原折行函数按**字符数**硬切，会把 ASCII 串拦腰截断：`…对外授权总额超1200亿美元`
  在第 22 字处切成「超12」+「00亿美元」。
- 改为**按显示宽度估算**（中文/全角按 1 个字宽，ASCII 按 0.55 估算），并**禁止在 ASCII 串中间断行**；
  同时补上标题行高与标签、产业链卡片的溢出保护。

### 尚未覆盖

- Banner 的中文标题仍按估算宽度折行，极端长标题（>60 字）会走「…」截断，属可接受降级。
